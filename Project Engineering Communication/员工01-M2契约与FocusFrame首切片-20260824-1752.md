- Effective Run Profile 记录实际 Provider/Model、reasoning、生成参数、上下文策略、工具权限、预算、值来源和能力快照；本切片是独立权威类型，尚未挂入 ModelRunRequest。

- 继续当前问题默认保留路径；聚焦新问题、从节点分支和原样续接仅接收显式包含/继承引用。
