## 相比上一份 PEC 的变化

- 上一版在每次查询时从 Confirmed Entity 临时重建本地向量；本版把版本化向量记录持久化到 SQLite，并增加完整性判断、真实损坏降级和显式重建命令。
- 上一版没有正式 Release；本版按唯一批准脚本发布统一 Build，并在无开发服务器条件下实际打开完整 MindScape 工作区。

## 本次完成

- schema 升至 v12，新增 `knowledge_vector_records`；v11→v12 自动校验并回填现有 Confirmed Entity，迁移前备份规则保持不变。
- Entity upsert 在同一 SQLite 事务同步 Entity、FTS 与 Vector：Confirmed 写入；Rejected/Superseded/Stale 等状态移除派生记录；实体删除同步清理 Vector、FTS 和相关 Relation。
- 持久化记录包含模型版本、维度、source hash、index version 与向量；读取时同时验证记录集合完整性和当前事实 hash。损坏 JSON、缺记录、旧模型、错误维度、非有限/零向量均返回 `vectorStatus=unavailable`，继续使用全文/关系候选并给出安全 notice。
- 新增 `rebuild_knowledge_vector_index` 服务与 Tauri IPC，前端 `kernelClient.rebuildKnowledgeVectorIndex()` 可按会话显式修复派生索引；重建先清空该会话索引，再从当前已校验 Confirmed 事实原子生成。
- 新增真实数据库回归：v12 回填、状态失效、重启向量一致性，以及“破坏 record_json→FTS 降级→重建→Vector 恢复”。

## 安全、数据与恢复边界

- 仅在本机 SQLite 保存确定性派生向量及版本元数据；API Key、Authorization、Provider 原始响应、reasoning 和用户数据库内容不进入日志、PEC 或验收 manifest。
