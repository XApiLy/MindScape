## 相比上一份的变化

- Review Lab 不再要求员工必须打开 GUI；新增 CMD / PowerShell 交互确认和 Agent 可调用的非交互参数入口。
- 新增固定 HTTP API 连接，其他员工工具可向同一串行构建队列提交可评审版本。
- 新增 Git 提交 Trailer 自动识别：每10秒检查新 HEAD，只消费明确的 `Review-Lab: preview/full`，普通提交和普通文件修改不会触发构建。
- 版本详情新增触发来源，能够区分 GUI、CLI、HTTP、Git自动识别和早期记录。

- 延续上一份已完成的产品共识、V1范围、岗位职责、总路线、M1派单、PEC规则和员工01～05当前 PEC 阅读结论。

- 未修改 `desktop/` 产品代码、Frozen V1领域契约、SQLite schema、Provider或凭据边界。
