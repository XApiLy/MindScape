## 已冻结的 UI 语义

- Off/Standard/Deep 分别由后端映射为 disabled/high/max；Custom 只提交 `reasoning_effort=high|max`，映射仍由员工05负责。
- `temperature/top_p` 若与 thinking 冲突，原值保留并明确阻塞发送；不会在切换模式时被清空。
- `contextPolicy` 当前按真实路径只读派生为 `continueCurrent / branchFromNode / continueImportedRaw`；`focusNew` 在 FocusFrame 生命周期命令完成前不伪装为可用。
- 工具权限固定显示“禁用”，因为当前 Provider/运行时未完成工具事件闭环；不把厂商原生能力冒充为产品能力。
- 结构化输出只在能力目录声明后可选；后端仍执行最终 provider/model/contract/参数校验。

## 契约、数据、安全与恢复影响

- 没有修改 Rust 权威类型、SQLite schema、凭据、导入或 M1 终态；只消费员工01/05已评审的可选加法字段。
- 档案不含 Key、Provider 响应正文或完整推理；本轮未调用真实 API、未产生模型费用。
- 创建时档案随持久化 `ModelRunRequest` 进入幂等比较；同一 key 不允许偷换参数。
- 当前 `ModelRunProjection` 不返回档案，因此应用重启后从投影恢复的重试尚不能复用原档案；实时会话重试已解决，重启场景需后端查询投影。
