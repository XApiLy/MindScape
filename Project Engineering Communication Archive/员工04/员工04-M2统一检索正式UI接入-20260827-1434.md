## 本次完成

- `App.tsx` 新增按节点缓存的统一检索状态：`knowledgeRetrievalByNodeId`、加载节点、错误映射；会话切换时完整清理，避免跨会话残留。
- 新增 `retrieveKnowledgeForNode`，调用 `kernelClient.retrieveKnowledge()`，经过 `projectKnowledgeRetrieval()` 后传递给画布；查询文本由用户明确提交，空文本被阻止。
- `ChatWorkspace` / `ConversationCanvas` / `CanvasFocusReader` 完成 typed props 贯通。
- 聚焦阅读器新增“统一知识检索”区域，支持：
  - 未查询、加载、成功、空候选、错误、重新检索状态；
  - 使用语义 `<form>` 支持键盘 Enter 提交，检索期间按钮禁用并显示加载状态；
  - 按内核原始顺序展示候选名称、稳定 ID、状态、整数分数和估算 Token；
  - 展示 Vector / FullText / Relation 来源、EvidenceTarget 类型和 embedding provenance 摘要；
  - 展示 omitted 排除原因与向量不可用/fallback 安全提示。
- 所有字段均为只读投影；不显示原文正文、向量正文、Key、Authorization 或 reasoning，不执行确认/否决和前端检索排序。
- 后续修正：Tauri 会话切换进入加载态时立即清空检索缓存，避免旧会话节点 ID 偶合时短暂复用旧候选。

## 契约、安全、数据与恢复边界

- 未改变 KnowledgeRetrieval、FocusedContext、FocusFrame、KnowledgeEntity、Relation、EvidenceRef 或 SQLite 契约；仅新增 UI 调用和只读展示。
- 查询结果按节点缓存并随会话切换清理；失败只写入安全错误映射，阅读器保持可重试。
- UI 不访问 SQLite/Markdown/VectorIndex，不把候选提升为确认事实；来源、排除和 fallback 语义由内核 DTO 保持权威。
