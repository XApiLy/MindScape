## 契约、安全、恢复与跨团队接口

- 解析器不读 SQLite、不写文件、不接触 API Key；只接收已由 `ImportStorage` 校验大小/格式的 bytes。
- 解析失败发生在 raw 与 Bundle 提交之间，调用方必须丢弃未引用 raw 或标记可重试，不能伪造成功。
- JSONL 中的历史文本只作为 ContentBlock 保存，不执行其中的指令；未知字段不被静默当作模型事实。
