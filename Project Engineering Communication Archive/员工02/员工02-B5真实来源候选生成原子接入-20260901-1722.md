## 本次推进的 B 编号

### B5-DATA：关闭员工02负责的候选生成持久化与来源校验接入

- schema 升至 v17，新增 `focus_promotion_candidate_generations` immutable receipt；相同 `generationId` 同 typed command 重放原 projection，不重新写 FocusFrame；同 ID 改变输入返回 integrity conflict。
- `SqliteStore → KernelService → Tauri command → lib.rs` 已接通 `generate_focus_promotion_candidates`。事务内重新加载生命周期与实体，校验 scope/status/EvidenceRef/revision，原子写入 FocusFrame、memory/lifecycle revision 与 receipt；stale 或任一写入失败整体 rollback。
- `KnowledgeEntity` 的普通 upsert 与 Markdown 编辑回流均在同一 transaction 校验 `ImportSource → ImportRevision → ImportedMessage.source_locator`，并同步嵌套 EvidenceRef 到独立 `evidence_refs`。无效 ImportContent 不会留下实体、FTS、vector、EvidenceRef 或 Markdown projection 的部分写入。
- B5 审计新增脱敏 `knowledgeInventory`：实体/证据/可解析导入来源/来源页计数及短指纹；缺失真实链路会明确失败，不能以手工编辑 SQLite 或 Vault 伪造样本。
