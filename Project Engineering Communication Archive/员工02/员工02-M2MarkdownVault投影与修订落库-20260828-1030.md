## 数据、安全、恢复与协作边界

- 原始导入内容不被 Markdown 覆盖；Markdown 是可重建投影，SQLite 仍是 revision 事实源。
- Vault 不写 API Key、Authorization、Provider 响应、完整 reasoning 或向量正文。
- 当前实现支持系统生成投影和历史 revision；用户直接编辑 Markdown 后的监听/命令回流与讨论日志仍需后续闭环。
