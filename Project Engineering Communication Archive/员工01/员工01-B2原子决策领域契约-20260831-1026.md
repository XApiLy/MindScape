## 本轮关闭的 B 编号

### B2：员工01“领域契约缺失”子阻断已关闭，B2整体未关闭

- 正式命令输入：`FocusPromotionDecisionCommandInput`。必填绑定 `decisionId`、`focusFrameId`、`candidateRef`、`expectedMemoryVersion`、`expectedLifecycleRevision`、`expectedEntityRevision`、`expectedDecisionRevision`、动作和时间。
- V1 决策为 create-only：`decisionId` 是稳定幂等键，首次写入要求 `expectedDecisionRevision = 0`；同一 ID 重试返回原决定，另一 ID 对同一 frame/candidate 必须由存储唯一约束拒绝。
- 动作语义冻结为四类：
  - `confirm`：只把候选确认为当前 FocusFrame 内事实，不自动进入主线。
  - `promote`：原子确认分支源实体，并以新的稳定实体 ID 在同 workspace 的 conversation/project scope 创建确认实体；保留 EvidenceRef。
  - `reject`：把候选转为 rejected，现有检索门禁立即排除。
  - `delete`：删除分支源实体，但必须保留不可变决策 tombstone，避免重启后从原 `promoteRefs` 复活。
- 只有 Closed、非主线、候选集合中真实存在且 scope 精确匹配该 FocusFrame 的 candidate/inferred 实体可以决策；memory/lifecycle/entity 任一版本陈旧均显式失败。
- Reopen 不撤销已持久化决定；Active 状态禁止新决策。重新关闭后，存储查询必须用决策 tombstone 过滤已处理候选。
- `plan_focus_promotion_decision` 输出 `FocusPromotionDecisionPlan`，同时包含前端可投影的终态决定和 `UpsertSource` / `Promote` / `DeleteSource` 实体变更意图，员工02应在一个 SQLite/Vault/FTS/Vector 事务内消费。

### B4：员工01接口评审通过，B4整体关闭

- 固定生产契约为 `paraphrase-multilingual-minilm-l12-v2-q-faf4aa4` / 384 维；普通状态检查只读本地文件，网络下载只由设置页用户明确安装动作触发，文件大小与 SHA-256 全部固定校验。
- 生产查询仅在 `SemanticEmbedding` 可用时生成真实 query vector；模型缺失、损坏、推理或重建失败时显式调用 `retrieve_knowledge_without_vector`，传入 unavailable snapshot，不会回落到 32 维 hash 向量。
- SQLite v15 只接受与 Confirmed 实体全集、当前 source hash、model version、dimensions、chunk version 一致的原子替换；实体内容更新会把真实语义索引标为 stale，否决/删除移除派生记录，重启读取仍按同一 contract 校验。
- 本地快速验证 marker 只信任已完成全 SHA 安装后的固定大小/mtime；本机攻击者同时篡改模型、mtime和 marker 不纳入普通损坏威胁面，该限制已在员工05 PEC 明示，符合当前本地数据信任边界。
