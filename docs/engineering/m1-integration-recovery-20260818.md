## 冻结审阅发现

1. 已忽略并禁止提交本地 Windows 调试 EXE 与 `target-fixed/` 等 Rust 生成目录。
2. 新增只输出“文件、行号、规则名”的密钥扫描，禁止在失败输出中回显疑似密钥。
3. 发现并修复重复 `run_id` 注册会覆盖原取消令牌的问题；现在只在运行表键空缺时注册，重复启动返回 `runAlreadyActive` 且保留原取消句柄。
4. 异步 Provider 任务异常退出时，先清理 active-run 表再返回错误，避免进程内留下无法再次启动的幽灵运行。
5. 真实 SQLite 基线确认两个 completed 运行均有用量、无永久 pending、无重复幂等键/序列、无孤儿运行；该证据不能替代取消、强退和重启验收。
6. 真实 Windows 双会话证据确认正常关闭重启后的节点、边、位置与 viewport 隔离恢复；强退和取消/失败状态仍需联合验收。

## 回滚与数据库注意事项

- 集成提交按一个恢复单元回滚；不得只回滚前端事件字段而保留 Rust 合同或数据库投影。
- schema v5 是前向迁移。已迁移的本地数据库不得交给旧二进制继续写入；迁移前备份机制必须保留，必要时使用备份恢复到旧版本。
- Provider 凭据只存在操作系统安全凭据存储；回滚、测试和证据采集均不得把 Key 写入数据库、日志、截图或 Git。
