# CAN-019：200节点画布计算基线

> 状态：M1首个可重复基线  
> 日期：2026-08-18  
> 负责人：员工03  
> 固定入口：`pnpm test:canvas:perf`

## 固定样本

- 200个完整问答节点、199条显式语义边。
- 节点ID、文本、时间和关系均为确定性数据，不使用随机数。
- 覆盖初次领域投影、平移、缩放、选中邻接边扫描和流式部分内容投影。
- 流式更新使用稳定`nodeId`合并`ModelRunProjection`，不创建第二张卡片。

## 2026-08-18基线结果

在当前Windows开发环境执行一次固定基准：

| 场景 | 操作规模 | 结果 |
| --- | ---: | ---: |
| 初次领域投影 | 200节点 / 199边 | 2.850 ms |
| 平移计算 | 5,000次 | 0.842 ms |
| 缩放计算 | 5,000次 | 1.890 ms |
| 选中邻接边扫描 | 1,000次 | 6.831 ms |
| 流式部分内容全投影 | 50次 | 132.220 ms |

命令输出同时校验节点数、边数和邻接选择结果，并设置宽松退化门槛，避免明显性能回退静默进入主分支。

## 当前结论与边界

- 领域投影和视口数学在200节点规模下没有发现计算层阻断。
- 固定高度节点使流式文本增长不参与自动坐标计算；更新只替换对应`nodeId`的内容与状态。
- 本记录是可重复的CPU计算基线，不等同于真实Tauri窗口的FPS、长任务、GPU合成或内存验收。
- M1联调仍需在真实Windows Tauri窗口记录平移、缩放、选中和流式期间的可见卡顿；M4由QA补齐正式帧率与内存门禁。
