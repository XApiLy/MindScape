## 2. 界面中的建议分组

字体选择器不做成一串无解释的名称，首批按阅读意图分组：

- **清晰正文**：Nunito、Lato、寒蝉半圆体。
- **轻松与个性阅读**：小赖字体、得意黑。
- **标题与氛围**：Caveat、Cormorant。

分组只是推荐，不限制用户选择。每张字体卡必须显示中文、英文、数字和常用标点的真实预览，并标注“适合正文 / 适合标题”“中文覆盖 / 西文为主”“可用字重”和回退状态；不能只用 `Aa Quick fox` 证明字体适合 MindScape 的中文长文。

## 3. 字体作用边界

一个阅读字体预设只改变阅读表面，不做全局暴力替换：

```text
阅读正文 / Markdown 标题 / 引用 / 列表 → 使用当前阅读预设及其回退栈
代码块 / 行内代码                       → 始终使用独立等宽字体
按钮 / 输入框 / 状态 / 导航 / 工具栏    → 保持 UI 字体和可访问性语义
原始 Markdown / 会话 / RAG / ModelRun   → 完全不变
```

- Caveat、Nunito、Lato 和 Cormorant 是西文为主的候选资源；遇到中文缺字必须进入明确的中文回退栈，不能由 WebView 随机决定。
- 参考图显示寒蝉半圆体、小赖字体和得意黑仅有 Regular。实际资源确认前，不允许浏览器合成伪粗体或伪斜体；Markdown 的 `strong` 必须通过已验证字重、颜色/字号层级或安全回退表达。
- 标题可以使用同一预设的层级字重，也可以在后续由员工06设计受控的标题/正文配对；M2 不建立任意字体混搭编辑器。
- 字体切换必须保持当前阅读锚点，不重跑模型、不修改原文、不改变上下文，也不能强制滚动到底部。

## 5. 实施前资源清单

每款要进入安装包的字体都必须建立一条资源记录：

```text
preset_id
display_name
font_file_name
font_family_from_metadata
version
supported_scripts
supported_weights_and_styles
source_url
copyright_holder
license_id
license_file_path
sha256
package_status
```

- 许可证核验以随实际字体包提供的 LICENSE/OFL 文件和官方来源为准，不能把参考图中的“免费/可商用”当作唯一证据。
- 保留原始许可证和版权声明；若字体经过子集化或转换，必须记录工具、输入 hash、输出 hash 和许可是否允许修改。
- 不从来源不明的网盘、截图页面缓存或二次打包站直接取字体。
- 字体文件进入正式工程后，还要复核安装包体积、首次加载、缓存和卸载清理。

## 6. M2 验收补充

1. 字体选择器完整列出七项预设，并用中文、英文、数字、标点和 Markdown 层级展示真实效果。
2. 预设资源尚未安装、加载失败或缺字时显示可理解的状态并安全回退，正文不可消失、乱码或阻塞。
3. 切换每项预设后，标题、正文、粗体、引用、列表、表格和链接层级仍然清楚；代码块保持等宽。
4. 寒蝉半圆体、小赖字体和得意黑在只有 Regular 时不生成伪字重；粗体语义仍可辨认。
5. 中文长文、英文长文、中英混排、数字/符号、超长表格和代码块都经过 1280×720、1600×1000、窄窗、125%/150% DPI 验收。
6. 字体偏好重启后保留；切换字体不改变 raw Markdown、数据库内容、复制 Markdown、导出、检索和模型请求。
7. 统一 Tauri Release 在断网环境下仍能使用已打包字体，不产生远程字体请求。
