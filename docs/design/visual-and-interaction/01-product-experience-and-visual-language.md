# 产品体验与视觉总纲

## 1. 产品给人的感觉

MindScape 不是 AI IDE、代码编辑器或本地执行 Agent。它服务聊天、学习、探索、项目讨论、创作与认知管理，核心竞争力是让用户更容易表达意图、控制模型、理解上下文、形成分支并把对话沉淀为成果。

界面需要同时满足两类用户：

- 想立刻开始的人：打开就能输入、选模型、发送或导入，不先学习一套复杂系统。
- 想精细控制的人：可以逐层展开思考等级、模型参数、分析范围、上下文、来源、工具轨迹和运行细节。

因此采用“简单默认、复杂展开”，而不是把产品切成互相隔离的硬模式，也不是把所有高级信息常驻在主界面。

## 2. 总体视觉原则

1. **内容优先**：阅读、输入、选择文字、停止运行和错误处理永远高于特效。
2. **状态诚实**：加载、发送、流式、停止、失败、恢复和未接入能力必须用真实文字与控件表达，不能由颜色、天气或动画代替。
3. **中心安静、边缘活跃**：视觉氛围优先存在于背景、卡片间隙、画布空白和窗口边缘。
4. **专注退让**：输入、聚焦阅读、文本选择、设置或对话框打开时，天气、云、雨和前景动效自动减弱或归零。
5. **低频而非噪声**：用缓慢、宽阔、偶发的运动建立空间感，避免高密度粒子和持续闪烁。
6. **组合而非捆绑**：背景、材质、氛围和区域覆盖相互独立。
7. **永远可降级**：Classic Opaque 是永久可用的安全表面；GPU或第三方视觉失败不能影响Chat。
8. **体验先被验证**：关键交互在真实原型和Tauri应用中确认，不以静态截图或抽象描述代替。

## 3. 保留的产品骨架

- 左侧会话与工作区导航。
- 中央 Chat / 无限画布双视图。
- 底部编辑器与固定的发送/停止操作位置。
- 节点、分支关系、从任意节点继续和聚焦阅读。
- 设置、上下文详情、导入入口、通知与错误处理。
- 模态关闭后的焦点恢复、键盘操作和视口恢复。

视觉升级应保留这些职责和心智模型，不重新发明业务组件树。当前暗色方向和空间骨架可继续作为基线，但完整品牌色、字体、间距、圆角、阴影和最终Design Token尚未全部冻结。

## 4. 分层视觉模型

```text
L0    背景：纯色、渐变、图片、视频、兼容的本地壁纸
L0.5  背景氛围：雨、云、雾、雪、光影
L1    轻微环境调整：亮度、色温、饱和度，可完全关闭
L1.5  空间氛围：位于背景和工作卡片之间
L2    主功能表面：侧栏、节点、阅读区、编辑器、设置区
L2.5  材质效果：模糊、折射、染色、高光、边缘
L3    直接控件：按钮、输入框、标签、选项
L4    临时浮层：菜单、对话框、通知、聚焦阅读
L4.5  前景氛围：仅少量出现在边缘，不持续穿过工作内容
```

最终解析模型为：

```text
ResolvedAppearance
= BackgroundTheme
× ComponentMaterial
× AtmosphereTheme
× RegionOverride
× RuntimeAttenuation
× DevicePolicy
```

真正保证可读性的遮蔽主要由 L2 局部表面承担，不能长期用整屏暗化把壁纸压黑。

## 5. 背景、材质与氛围

所有主要组合都必须合法：颜色或壁纸背景，都能搭配不透明、毛玻璃或 Liquid Glass。用户先选择全局材质，再按侧栏、节点、阅读区、编辑器、设置/浮层进行区域覆盖。

已冻结的原型来源职责：

| 职责 | 来源 | 作用 |
| --- | --- | --- |
| Liquid Glass | Ybouane LiquidGlass | 折射、色差、Fresnel、边缘高光与曲面 |
| 毛玻璃 | Glacé | 模糊、边缘折射、bezel、profile、sheen |
| 天气 | React Weather Effects | 雨、雪、雾与前后景天气预设 |
| 云 | Drei `Cloud` / `Clouds` | 多层低频漂移的云团 |

雨滴保留两套可切换引擎：统一光学方案与原仓 Weather Effects。雨滴层级只决定合成位置，可位于环境下层、组件表面或全局透明覆盖；它不能拦截输入，也不能因层级变化复制模拟。

## 6. 明确避免

- 把“有壁纸”等同于“所有组件必须透明”。
- 所有层级都使用强玻璃、强反射和粒子，造成视觉疲劳。
- 特效持续穿过正文、输入框、菜单、节点操作柄或错误主操作。
- 用天气、Shader或颜色表达成功、失败、思考中等业务事实。
- 为了高级感默认加载Three.js、重型粒子或没有明确价值的3D场景。
- 把参考原型中的超范围模块误当成已经确认的产品需求。
- 为材质效果牺牲文本选择、焦点、键盘、响应速度或低性能设备可用性。
