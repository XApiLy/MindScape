# MindScape MVP 开发基线

> 本文保留早期技术基线与演进记录；第一版正式产品范围以 [第一版产品规划与范围边界](v1-product-scope.md) 为准。  
> 状态：开发中，首个可运行原型已完成  
> 最近更新：2026-08-14

## 1. 首版验证的问题

> 用户能否在无限画布中创建、分支和接续 AI 会话，并把其他平台的历史会话导入后，选择任意厂商模型继续工作？

## 2. 首个端到端闭环

```text
创建空白会话或导入 Markdown / JSON / JSONL
→ 本地解析并保留原文轨
→ 选择原样继续 / 快速识别 / 详细分析
→ 可选生成接续轨
→ 在无限画布中生成会话节点和关系
→ 选择厂商与模型并继续流式对话
→ AI 自动发现和调用内部认知工具
→ 展示活动轨迹、上下文片段、工具结果和引用
→ 将新消息、分析层和用户纠正保存到本地
```

漫游分析只保留入口和数据结构，首版可以先不实现完整配方系统。

## 3. 首版界面

### 左侧

- 会话列表
- 导入会话
- 新建会话

### 主工作区

- 无限二维画布、缩放、平移和小地图
- 可拖拽会话卡片与来源连线
- 深入、发散、换角度三种分支
- 聚焦阅读视图
- 固定底部输入区、模型选择和流式状态

上下文、Skill、工具调用和引用优先作为节点内可展开轨迹呈现；待信息密度验证后再决定是否增加固定右栏。

## 4. 首批内部工具

只实现能够验证认知工具调用的五项能力：

1. `search_conversation`：搜索当前导入会话并返回原文引用。
2. `read_context`：读取用户明确选择的上下文片段。
3. `create_note`：创建可撤销的会话笔记。
4. `create_branch`：从选中消息创建探索分支。
5. `build_relation_view`：根据选中内容生成简单的关系节点与边。

网页搜索、PDF、音视频、云同步和分享在后续里程碑接入。

## 5. 数据内核

首版必须从一开始保存：

- 会话及来源
- 消息与内容块
- 附件元数据
- 原文轨
- 接续轨及其版本
- 用户纠正
- Skill 挂载事件
- 工具调用、输入范围、结果和错误
- 引用关系
- Token 与耗时记录

原始导入文件不可变；所有分析均作为派生版本保存。

## 6. 推荐工程默认值

- 桌面壳：Tauri v2
- UI：React 19 + TypeScript + Vite
- 样式：Tailwind CSS v4
- 本地数据：SQLite
- 状态：按领域拆分，事件持久化与 UI 临时状态分离
- 模型层：统一 Provider 接口，首批支持 OpenAI-compatible、Anthropic、Gemini，并兼容 DeepSeek、OpenRouter 和自定义服务
- 流式协议：统一消息事件，包括文本、工具请求、工具结果、引用和错误
- 密钥：操作系统安全凭据存储，不写入 SQLite 和日志

画布首版使用 React Flow。PixiJS、Three.js、LanceDB 和复杂着色器暂不进入首个闭环。

## 7. 开工前必须确认的四个选择

### A. 首个模型接入

首版直接维护统一多厂商适配层。实际联调仍应先选一个稳定模型跑通鉴权、流式响应、限流和错误处理，再逐家完成契约测试。

### B. 调用付费方式

需要在两种方案中选择：

- BYOK：实现快、无需平台计费，但首次配置更复杂。
- 平台代理：体验统一，但需要后端、账号、额度、风控和成本控制。

推荐 MVP 先用 BYOK，后续增加平台代理。

### C. 数据默认位置

推荐 MVP 默认本地保存，不要求登录；云同步晚于核心聊天闭环。模型调用仍属于云端处理，发送范围必须透明。

### D. 首个导入样本

需要至少一份真实 Claude 或 Codex 导出记录，用于确定字段、附件和工具调用格式。没有真实样本时先完成 Markdown / JSONL 通用导入器，不凭空猜平台格式。

## 8. 可以暂缓讨论的内容

- 最终品牌视觉与七层玻璃效果
- 3D 场景和大型画布性能优化

## 9. 开发里程碑

### M0：项目骨架

- Tauri、React、TypeScript 和 Vite 可运行。
- 提供基础导航、无限画布、导入器和模型配置界面。
- 状态模型支持会话节点、关系、导入来源和供应商配置。

状态：原型已完成；SQLite 持久化与安全凭据尚未接入。

### M1：基础聊天

- 接入统一多厂商模型适配层。
- 流式消息、停止、重试和错误展示。
- 会话本地持久化。

状态：流式适配器和演示聊天已完成；真实密钥联调、停止与重试待完成。

### M2：会话导入与双轨

- Markdown / JSONL 导入。
- 原文浏览。
- 原样、快速和详细分析入口。
- 接续轨生成、修正和删除。

状态：通用解析和三档入口已完成；真实 Claude、Codex 导出格式与分析服务待联调。

### M3：工具调用与透明轨迹

- 接入首批五个内部工具。
- 展示 Skill、上下文、工具输入输出和引用。
- 简洁、标准和专家三种信息密度。

### M4：验收

- 使用真实外部会话完成一次接续。
- 对比原样与快速分析的质量、Token 和延迟。
- 验证分析可撤销、引用可回溯、工具失败不伪装成功。

## 10. 首版完成标准

用户能够在不阅读教程的情况下：

1. 导入一段会话。
2. 理解三个分析档位。
3. 继续向 AI 提问。
4. 看见 AI 使用了哪些上下文和工具。
5. 点击引用回到原始消息。
6. 删除分析层后仍保留完整原文。
7. 关闭并重新打开软件后继续当前工作。
