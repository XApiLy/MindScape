# MindScape 桌面端本地数据布局

> 责任任务：DATA-001、DATA-002、DATA-003  
> 状态：第一周技术底座  
> 数据根目录：由 Tauri `app_data_dir` 按操作系统确定

## 物理目录

```text
<app_data_dir>/
├── mindscape.sqlite3   结构化领域数据与事件
├── imports/            原始导入内容（后续 DATA-009 接入）
└── backups/            数据库迁移前恢复副本
```

数据库、原始导入内容和恢复副本必须保持独立。React 状态、浏览器
`localStorage` 和构建目录均不是正式数据源。

## SQLite 连接规则

每个连接必须启用外键，使用 WAL 日志、`NORMAL` 同步级别和 5 秒忙等待。
领域写入通过事务提交；事件账本与其对应的领域变更必须处于同一事务。

## 迁移与恢复规则

- 迁移按单调递增版本执行，每个版本在独立事务中提交。
- 已有数据库升级前先执行 WAL checkpoint，再在 `backups/` 中生成带旧
  schema 版本和 UTC 时间的副本。
- 全新数据库不生成无意义的迁移备份。
- 遇到高于当前应用支持范围的 schema 时拒绝启动，禁止隐式降级或改写。
- 迁移失败时保留升级前副本；自动恢复与用户提示将在 DATA-014、DATA-018
  中接入启动恢复流程。

## 安全边界

API Key 不属于上述任何普通文件或 SQLite 表。正式凭据只能由操作系统安全
凭据设施保存，数据库后续只允许保存不具备秘密值的凭据引用。
